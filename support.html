Moving notes from ColorNote (Android)

  1. In ColorNote: Settings → Backup → Backup notes, then tap the backup → Send and get the file to your iPhone (email, Google Drive, OneDrive…).
  2. In HueNotes: More → Import ColorNote backup → choose the file.
  3. Enter your ColorNote master password (0000 if you never set one) → Decrypt backup → Import.

Locked ColorNote notes are encrypted a second time with a key that isn't in the backup. Unlock them in ColorNote before backing up, then import again; notes you already have are skipped.

Google Keep, Evernote, Apple Notes, Markdown

More → Import from Keep, Evernote, Apple Notes… shows the export steps for each app. Pick the files, a folder or the .zip as downloaded.
